# Third-party notes
Interaction patterns (cursor spotlight, magnetic button, tilted card, sliding pill navigation) follow ideas from React Bits (https://reactbits.dev, MIT + Commons Clause).
No React Bits source code is included; `src/fx.js` and `src/motion.css` are original implementations for this project.
If React Bits component code is added later, keep its licence notice and do not redistribute the components as a standalone library.
Runtime dependency: `qrcode` (MIT).
